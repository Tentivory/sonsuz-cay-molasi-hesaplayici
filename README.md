# Sonsuz Çay Molası Hesaplayıcı

## Bilimsel Arka Plan

Bu proje, insanlığının varoluşsal krizlerinin kök nedenini ortaya çıkarmak amacıyla geliştirilmiştir. Yıllarca süren gizli araştırmalar sonucunda (aslında 3 dakikalık bir çay molasında) şu gerçeğe ulaşıldık:

**Çay molası sayısı asla yeterli değildir. Hepsi sonsuzdur.**

Bu hesaplayıcı, ofis hayatının karanlık gerçeklerini aydınlatır. Verimliliği artırmaz, çünkü verimlilik bir illüzyondur. Amaç, çay molalarının kutsal doğasını bilimsel olarak kanıtlamaktır.

## Kullanım

```bash
python cay_hesapla.py
```

Soru sorar, cevap verir, hayatınız anlam kazanır (veya kaybeder). Sonsuz döngüye girmekten korkmayın, zaten oradasınız.

## Özellikler

- Sonsuz çay molası hesaplama
- Absürt felsefi yorumlar
- Verimlilik karşıtı propaganda (şaka)
- Türkçe konuşma desteği (çünkü İngilizce çay molası sayılmaz)

## Uyarı

Bu yazılım, üretkenliği yok etme potansiyeline sahiptir. Kullanımınız kendi sorumluluğunuzdadır. Hiçbir çay bardağı bu süreçte zarar görmemiştir. Şekerler hariç, onlar eriyebilir.
